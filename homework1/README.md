# Homework 1 -- CS-4300
## How to run
### Step 1. Clone the repository
```bash
git clone https://github.com/Lumbag0/cs4300.git && cd cs4300
```
### Step 2. Make a virtual environment
```bash
python3 -m venv venv
```
### Step 3. Activate virtual environment
```bash
source venv/bin/activate
```
### Step 4. Install Requirements
```bash
pip3 install -r requirements.txt
```
### Step 5. `cd` into homework1 folder
```bash
cd homework1/
```
### Step 6. Run the tests
```bash
pytest
```
### Step 7. Run the programs
- Note: All programs can be ran with this command (did not use arguments). Just substitute out the number for whichever task you want to run.

```bash
python3 task1.py
```
